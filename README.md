# AWS Legacy WordPress Migration Using Terraform

## Project Overview

This project demonstrates my hands-on experience deploying a WordPress website on Amazon Web Services (AWS) using Terraform and Linux administration skills.

I used Terraform to provision an Amazon EC2 instance running Ubuntu Linux. I configured networking and security rules, installed Apache, PHP, and MySQL, and deployed WordPress to create a working cloud-hosted website.

## Technologies Used

- Amazon Web Services (AWS)
- Terraform (Infrastructure as Code)
- Amazon EC2
- Ubuntu Linux
- Apache Web Server
- PHP
- MySQL
- WordPress
- AWS Security Groups
- Elastic IP

## Project Implementation

1. Created Terraform configuration files to provision AWS infrastructure.
2. Deployed an Ubuntu Linux EC2 instance.
3. Configured security rules for SSH and HTTP access.
4. Connected to the EC2 instance using SSH.
5. Installed and configured Apache, PHP, and MySQL.
6. Created a MySQL database and database user for WordPress.
7. Installed and configured WordPress.
8. Troubleshot network connectivity and missing PHP extensions.
9. Configured an Elastic IP to maintain a consistent public IP address.
10. Verified the WordPress website was accessible through a web browser.

## Skills Demonstrated

Successfully deployed and accessed a WordPress website hosted on an AWS EC2 instance. This project strengthened my practical understanding of cloud infrastructure, automation, Linux administration, and troubleshooting.
